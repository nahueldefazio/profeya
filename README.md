# ProfeYa - Landing Page

Landing page para clases particulares universitarias con el diseño Académico: azul profundo, tipografía editorial y gráficos de análisis matemático.

## Características

- ✅ Diseño moderno y responsive
- ✅ Sección de materias disponibles
- ✅ Información sobre tipos de clases
- ✅ Metodología de trabajo
- ✅ Contacto directo por WhatsApp

## Materias

- Análisis Matemático
- Matemática
- Física
- Química
- Biofísica
- Probabilidades y Estadísticas
- Teoría de Circuitos
- Técnicas Digitales
- Sistemas de Comunicación

## Tecnologías

- HTML5
- CSS3
- JavaScript sin dependencias para las entradas al hacer scroll. El contenido también es accesible sin JavaScript.
- Animaciones de entrada, trazado del gráfico y efectos de interacción; respetan la preferencia de movimiento reducido.
- Google Fonts para las tipografías, con fuentes alternativas si no hay conexión.

## Instalación

Simplemente abre el archivo `index.html` en tu navegador.

Los estilos de la página principal están en `styles.css`. Las tres propuestas originales se pueden comparar abriendo `disenos.html`.

## Personalización

Para cambiar el número de WhatsApp, reemplaza `5491144361290` en todos los enlaces de `index.html` por el número real con código de país, sin espacios. Actualiza también el enlace `tel:` y el número visible del pie de página. Cada materia incluye un mensaje de consulta predefinido.
