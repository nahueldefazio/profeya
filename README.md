# ProfeYa - Landing Page

Landing page para clases particulares personalizadas de nivel secundario y universitario.

## Características

- ✅ Diseño moderno y responsive
- ✅ Sección de materias disponibles
- ✅ Información sobre tipos de clases
- ✅ Metodología de trabajo
- ✅ Contacto directo por WhatsApp

## Materias

- Análisis Matemático
- Matemática
- Física
- Química
- Biofísica
- Probabilidades y Estadísticas
- Teoría de Circuitos
- Técnicas Digitales
- Sistemas de Comunicación
- Ofimática (Excel, Word, PowerPoint)

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla)

## Instalación

Simplemente abre el archivo `index.html` en tu navegador.

## Personalización

Para cambiar el número de WhatsApp, edita el archivo `index.html` y busca:
```html
<a href="https://wa.me/54911XXXXXXXX" target="_blank" class="btn btn-whatsapp">
```

Reemplaza `54911XXXXXXXX` con tu número real (formato: código de país + número sin espacios).
